# 设计说明 · Design

## 0. 一句话

**让观众走进一幅“黄色的交响曲”，再看着它拆成笔触、长成花、走完一生、慢慢褪色，最后在烛光里重新亮起。**
每一章都只做一件事，并且都可以“上手”：光标是太阳，色带可以听，花可以转，时间可以拖，画布可以画。

## 1. 叙事与滚动编排

整站是一条连续的滚动“镜头”。`src/gl/Engine.ts → direct()` 以**各章节内的相对滚动位置**（单位：视口高度）驱动所有参数，
用 `seg(x, a, b)`（线性区间）与 `stair()`（阶梯）组合出关键帧，并把 `--p / --e / --l`（进度 / 进入 / 离开）写成 CSS 变量，
让 DOM 文案与 WebGL 画面完全同步淡入淡出。

| 章节（高度） | 画面 | 关键参数 |
|---|---|---|
| 序 · 向日葵（175vh） | 4 层景深立体画，镜头推进 3.6 单位 | `dolly`；入场 2.8 s 笔触显影（按真实时间，不受帧率影响） |
| 01 · 三十三种黄（430vh） | 画面以“笔触碎片”溶解 → 48 000 笔真实笔触飞起 → 按明度长成颜色之花 → 坍缩成一粒种子 | `swap → morph → collapse`；背景转为普鲁士蓝 |
| 02 · 粗粝有刺的生命（450vh） | 种子长成 3D 向日葵：蓓蕾 / 盛放 / 凋萎 / 结籽 | `appear`、`life`（阶梯式 0–3）；背景转为阿尔勒早期版本的蓝绿 |
| 03 · 画会像花一样褪色（330vh） | 画面以笔触重新“画回来”，随后 1888 → 2150 老化 | `repaint`、`age`（滑块可接管，离开章节后交还滚动） |
| 04 · 留下你的一笔（1 屏） | 独立 WebGL 厚涂画布 | 进入视口自动“种一朵”；离开时主场景暂停 |
| 尾声（190vh） | 烛光夜景：普鲁士蓝月色 + 光标烛灯 + 花朵自发光 | `night` |

**转场的“笔触溶解”**：`Diorama` 片元着色器里的 `dabs()` 是一种各向异性 Voronoi——每个单元是一笔沿局部流向旋转的椭圆笔触，
各自带一个随机阈值，再叠加低频噪声形成大尺度的“扫笔”方向。画面因此是**一笔一笔**地消失/出现（刚落下的一笔会闪一下湿颜料的高光）。
早期版本用全局旋转的 hatch 噪声，会在大坐标处产生同心涡纹，已替换。

## 2. 章节与交互细节

### 序 · 向日葵（Hero）
- **景深立体画**：背景墙（z −1.8）、花瓶花束（z 0，160×107 网格按“形体高度图”外凸）、桌面与落花（z 0.55）、虚化前景（z 3.2）。层间视差随光标和滚动变化。
- **光标是阿尔勒的太阳**：每层用自身亮度的高频分量作为浮雕高度，实时求法线做 Lambert + Blinn-Phong；光源位于光标处。
- **按住 = 侧光（raking light）**：光源压低到画面几乎平行，环境光降低、光池收紧，颜料的厚度一下子“站”起来——就像修复师用侧光检查画面。
- **点击一朵花**：花头在着色器里做旋转扭曲（弹簧阻尼），迸出花瓣粒子，并奏出与这朵花位置对应的和弦。
- **取色放大镜**：光标旁显示其下那一种黄的名称与色值（来自 `palette.json`）。

### 01 · 三十三种黄
- `StrokeField`：从母版图按网格抽样 ~48k 点（移动端 24k），用结构张量求每处的笔触方向，挑选 4×4 真实笔触图集中的一笔。
- 每一笔被分到最近的调色板颜色（OKLab），整体按“色族明度 → 自身亮度”排序，然后由 `layoutFlower()` 在 CPU 上排成一朵花：
  - **最暗的 40% → 花盘**：377 个（移动端 233 个）种子按 Vogel 模型排布，每粒种子是一个小漩涡：暗色在外圈、亮色在核心，花盘略微隆起。
    参与排序的键带抖动，所以每粒种子都混合了邻近的几种明度，斐波那契螺线自己浮现出来，而不是生硬的同心色环。
  - **较亮的 60% → 两轮舌状花瓣**：后排 21 瓣（偏暗、偏橙）、前排 13 瓣（更亮，绘制在上层）；
    笔触沿每片花瓣弯曲的中心线方向排布，按宽度轮廓的反 CDF 均匀填充；花瓣有共同的轻微偏转（像风车，像“跳跃的太阳”）、在深度上向后卷曲，并缓慢摇曳。
- **听见每一种黄**：悬停色带或花盘，`Synth` 以五声音阶奏出这种黄——越亮音越高，越饱和音色越亮。
- **聚光**：被选中的那种黄的笔触抬起、放大、提亮；其余笔触沉入暖褐色阴影（不是灰色），花的轮廓仍在。
- 拖拽可 3D 旋转这朵花；继续滚动，所有笔触坍缩成一粒种子，引出下一章。

### 02 · 粗粝有刺的生命
- `Sunflower`：程序化 3D 向日葵。花盘为 AI 绘制的种子盘纹理 + 亮度浮雕；34 外瓣 + 21 内瓣 + 21 苞片，均为实例化曲面，由同一组参数（open / droop / dry / fall / nod）驱动。
- **蓓蕾**：苞片变长、强烈内卷，像绿色的穹顶包住缩小的花瓣；**盛放**：完全展开；**凋萎**：花瓣卷曲下垂、铬黄退成赭黄、花头低垂；**结籽**：花瓣脱落飘下，只剩沉甸甸的花盘。
- “显示 34 / 55 螺线”：在花盘上以精确的 Vogel 模型（987 粒种子）生成两族螺线带，按扫描动画依次点亮。
- 阶段按钮可直接跳到对应滚动位置。

### 03 · 画会像花一样褪色
- 年份滑块 1888 → 2150（今天 2026 有刻度），同时也会随滚动自动推进；`ageColor()` 的三步模拟见 [research.md](research.md#3-颜料科学为什么画会褪色)。
- 页面注明这是艺术化模拟。

### 04 · 留下你的一笔（PaintStudio）
- 独立的 WebGL 渲染器，半浮点渲染目标同时存储**颜色与颜料高度**（自定义混合），笔刷是真实笔触图集的盖章；颜料随拖动逐渐“干”掉（dry-brush）。
- 显示通道：亚麻画布纹理 + 由高度求法线 + 跟随光标的侧光，所以每一笔都有厚度。
- 调色盘：铅白 + 每个黄色族一种 + 普鲁士蓝 / 维罗纳绿 / 熟赭（呼应信 740 的“三种铬黄、黄赭和维罗纳绿”）。
- **种一朵向日葵**：一段程序化“作画”——先铺满淡黄墙面的漩涡笔触，再画赭色桌面与梵高式的蓝色边线，然后是双色釉的陶罐与蓝色轮廓、
  茎和叶，最后是四个花头（盛放、侧转、凋萎、蓓蕾——又一次生命周期）、Vogel 花盘与高光，以及桌上两片落瓣。
- 保存：导出 PNG，右下角盖朱红“向日葵”印章。

### 尾声 · 一首蓝与黄的交响曲
- 夜色：整幅画转为普鲁士蓝的月色，光标处是一圈暖色的烛光；每朵花自己发光，像梵高说的“落地灯或烛台”。
- 引文 666 与 806、制作说明、全部资料链接、回到开头。

## 3. 色彩

- **黄**：全部来自 `palette.json` 的实测 33 种黄（11 个色族），界面色票、颜色之花、声音、工作室调色盘都用同一份数据。
- **蓝**：梵高的“蓝与黄的交响”。界面强调色是普鲁士蓝（#16324F 一系），三处背景转场：
  1. 01 章：普鲁士蓝夜空般的厚涂漩涡——让黄最亮；
  2. 02 章：蓝绿（teal），参照 1888 年 8 月最早几幅阿尔勒向日葵的蓝绿背景；
  3. 尾声：深夜蓝。
- `Backdrop` 是全程序化的厚涂背景：流场引导的椭圆笔触（每笔带脊线高光与阴影）、四套调色板按章节混合、光标处有一盏小灯，以半分辨率渲染再合成以节省性能。

## 4. 文字

- 中文正文：Noto Serif SC（子集化 610 字）；书法标题：马善政楷书 Ma Shan Zheng（子集化）；拉丁文：Fraunces（SOFT 100 / WONK 1，可变字重 300–700）。
- 竖排“向日葵”+ 朱红“梵高”印章，呼应东方题跋；章节标题用容器查询单位（`cqw`）自适应，保证书法标题永远一行、不会落单一个字。
- 所有字体本地自托管（`src/assets/fonts`），修改文案后需运行 `scripts/subset_fonts.py`。

## 5. 声音

`src/audio/Synth.ts`：纯 Web Audio 合成，默认静音（入口可选“带声音进入”）。五声音阶保证任何手势都和谐；
每种黄 → 一个音高（明度）与音色亮度（彩度）；点击花朵奏和弦；章节背景有极轻的持续音垫；卷积混响由程序生成的脉冲响应构成。

## 6. 无障碍与适配

- 全部可交互元素有 `aria-*`、可键盘聚焦；色带每个色票都有中英文名与色值标签；生命周期按钮使用 `aria-current`。
- `prefers-reduced-motion`：关闭摇摆、漂浮、自动旋转，入场缩短到 0.6 s。
- 移动端：笔触数减半、背景 0.5× 分辨率、DPR 上限、按帧时自适应降分辨率；触屏只用横向拖动旋转，避免与滚动冲突；卡片取消毛玻璃以省性能。
- 无 WebGL2：显示静态母版图与全部文案（`.static-bg`）。
